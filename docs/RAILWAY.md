# Railway deployment candidate
Use a confirmed free workspace only, with no paid plan or automatic charges. Connect the new repository and select its Dockerfile. Attach a persistent volume at `/data` and verify write permissions for UID 10001; do not run the app as root. Set `BC_ROOT=/data`, `BC_TLS=1`, `BC_HOSTS=<actual Railway hostname>`, `BC_ORIGIN=https://<actual Railway hostname>`, and `PORT=8765`. Set the domain target port to 8765. Create accounts through the operator CLI on the mounted volume using a secure console; never put passwords in Git, build args or logs. Do not enable public use until the release gates have passed. Stop deployment if free capacity cannot be guaranteed. A successful healthcheck alone is not a security certification.
