# Dependency and supply-chain policy
Direct dependencies are pinned in requirements.txt; this is not a hash-locked transitive dependency set. PDF generation adds WeasyPrint and requires native Pango, HarfBuzz and Noto fonts (including CJK and Devanagari support). Dockerfile and international CI install these OS packages. OCR uses Tesseract with English and Spanish models. Fresh installation and Docker build/scan still require CI. Review dependencies, generate SBOM, check vulnerabilities, pin verified base image digests and action SHAs before production. No Hermes dependency or paid API required.
