# Ledger64 v0.1.1 — International showcase & local quick start

This stable-source patch improves discovery, installation and documentation without merging the experimental procurement extension or changing the financial engine.

## Highlights
- Nine interface and documentation languages: English, Español, Français, Italiano, Deutsch, Português (Brasil), 简体中文, 日本語, हिन्दी.
- C64-inspired authenticated interface, captured in a real Chromium session with synthetic invoices (English and Spanish).
- Loopback-only Docker Compose quick start: `docker compose -f compose.local.yaml up --build -d`; persistent local data, no default credentials, separate account creation.
- Reworked README, Mermaid architecture, SME purchasing use cases and links to both stable and experimental documentation.
- Deterministic invoice checks, recent supplier comparisons, estimated savings, reviewed OCR, independent governance and local reports.
- Nine-language static procurement simulator is a separate illustration, not a hosted Python backend.

## Validation
Publication is gated by container acceptance (including vulnerability scans), international browser and PDF acceptance, synthetic learning acceptance, local Compose smoke/persistence checks and screenshot capture. Source and screenshot files are distributed with SHA-256 checksums. The previous v0.1.0 release remains unchanged.

## Experimental branch
The procurement pilot remains separate: cumulative three-way matching, partial deliveries, multiple invoices, OCR tables, reviewed supplier layouts, revisions and recovery. Baseline 108/108 synthetic tests passed at f9fd4a66. Not included in this stable runtime. See draft PR #2.

## Scope and limitations
Synthetic data only until deployment-specific security, privacy and real-document validation pass. No tax/accounting certification, payment execution, general invoice extraction guarantee, or realized savings claim. OCR language packs are English and Spanish. ALE is supervised, offline and experimental. The MIT original code and third-party licenses remain unchanged.

## Assets
Source archive, SHA-256 checksums and real synthetic C64 screenshots. Follow README for local setup and RELEASE.md for deployment constraints.
