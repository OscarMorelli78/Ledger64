# Validation
`python scripts/check.py` runs inherited regression, locale tests, ALE unit tests and nine-language HTTP acceptance. `python scripts/browser_acceptance.py` requires Playwright and Chromium. Run `International acceptance` in GitHub Actions to verify the real browser. `Container CI` builds and tests Docker; run the workflow defined in `.github/workflows/container.yml`. The corpus generator processes 10,000 synthetic documents across 20 sectors; this is not a real-world or concurrent HTTP evaluation. See ACCEPTANCE.md for evidence and pending gates. Review quotas before running workflows. No production approval until all release gates are independently verified.
