# Support / Soporte

## Community (free)

Use the manuals in `docs/manual/` once the source import is complete, existing issues and the bug template. Include version, operating system, synthetic reproduction and expected vs actual behaviour. Community support is best-effort, without a response-time guarantee.

## Professional (paid, by agreement)

Installation, onboarding, integrations, maintenance and prioritized assistance can be scoped through [CONTACT.md](CONTACT.md). Response windows, coverage, exclusions, backup responsibilities and fees must be agreed in writing. No paid support contract is active by default.

Security vulnerabilities: follow SECURITY.md once available, never a public issue. Never attach invoices, tax records, credentials, personal data or production logs. Use fabricated reproductions.
