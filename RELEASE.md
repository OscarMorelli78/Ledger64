# Deployment guide — production approval is separate
Requires a Linux host with Docker Engine + Compose, DNS A/AAAA for an owned domain, ports 80/443, encrypted host volume and offsite encrypted backups. No credentials are included. Set BC_DOMAIN and optional BC_ACME_EMAIL in .env. Traefik is the default HTTPS reverse proxy (file provider only, no Docker socket, ACME persistent state in proxy_data). Ensure ports 80/443 and DNS are correct before requesting certificates. The legacy Caddyfile is retained for reference only; do not use its unscanned image. Existing business_data remains unchanged; do not remove volumes during migration. Build and pass container.yml including Trivy and 10k corpus before deploying; the versioned source release also requires international and learning acceptance. Then `docker compose up -d --build`. Provision accounts via `docker compose exec app python admin.py company NAME` and `docker compose exec app python admin.py user COMPANY_ID LOGIN --role owner` (interactive password), plus distinct analyst/reviewer. Check HTTPS, cookie flags, external access, isolation, restore, load, logging and privacy before using real data. App remains private behind proxy. Public TLS, backup and deployment-specific tests remain the operator's responsibility. Image tag dependencies need pinning and vulnerability scanning. Existing app has single-worker SQLite and global proxy-visible login IP; evaluate per-user rate limits before public access. No production launch, billing, or external account changes performed.
