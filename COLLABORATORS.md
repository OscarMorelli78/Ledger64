# Global contributor programme / Programa de colaboradores

Ledger64 welcomes contributors from every country and language. Participation is voluntary; no employment, compensation, revenue share or access to private data is implied.

| Track | First contribution | Review |
|---|---|---|
| Translation | Improve a locale or manual | Native-language review; glossary consistency |
| Engineering | Reproduce a bug with synthetic inputs | Tests, independent review, no financial regressions |
| Security | Report privately | Security policy |
| Documentation | Improve an install guide | Reproducible instructions |
| Integrations | Propose an adapter | Minimal permissions; synthetic contract tests |

Start with [issues](https://github.com/OscarMorelli78/Ledger64/issues). When the full source is imported, read CONTRIBUTING.md, fork, create a focused branch and submit a pull request. Contributions are under MIT; credit is retained in Git history. No confidential records, private learned parameters or third-party code without compatible rights. Maintain a respectful and inclusive community. Contributors can opt out of public acknowledgements beyond Git history. Maintainers decide acceptance; review and access are not automatic.
